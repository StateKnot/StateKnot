# Independent review and adoption records

This appendix is assembled by the test/publication author. It records other reviewers' fixed-scope originals; it is not an independent verdict by the delivery author. The seven original groups are docs preflight v1 (accepted finding), docs v2 closure, final docs Spec v3, full publication-v3 Standards/Spec and their two publication-v4 packaging increments. The original v3 verdicts retain their exact v3 subject; the two increments bind current v4. Publication Standards includes its first collector failure. A separate non-review archive group preserves the original staged helper EOF check receipt/stdout/stderr and commit-attempt posthoc record (commit command not reached, no commit created); this is a packaging failure, not a product or Rust-test failure. Original manifests/receipts/failed observations remain unchanged inside one deterministic lossless tar.gz; no archived program is executed.

Six source-review groups (Standards v1-v5 and implementation Spec) are already in the base component archive. `delivery.json` names the exact existing archive/member/raw hashes, without duplicating them. Source Spec discloses authorship of the originating contract, not production/tests. The production author performed publication Standards as a non-author of that package; it is not independent production-code Standards. Review axes and author roles must not be interchanged.

The base component seal's pending publication/adoption fields describe that seal's original time and are not retroactively changed. These later independent records are separate.

The six adoption originals are non-review records: plan and actual9-path code/docs copy, original v3 publication plan/copy, and current v4 publication plan/copy. The old v3 copy remains bound to the old v3 review receipts; the v4 copy binds the two packaging-only increments. They establish only the recorded paths/540-input workspace bytecheck. Original pending fields in the plan remain historical. They confer no new gates, wholeGit/compiler read closure, commit/push, Native, fullCI or R1 qualification.

Run `python3 -B verify.py --repository-root /path/to/repository`. The verifier checks hashes, decodes archives in memory, checks each original manifest, and verifies exact existing source-review archive references. It never executes preserved review scripts or runners.
